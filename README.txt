Orisma Global Landing Page

Files included:

- style.css
- orisma-logo.png

How to upload:
1. Extract this ZIP file.
2. Upload index.html, style.css, and orisma-logo.png to your hosting public_html or website root folder.
3. Make sure all three files remain in the same folder.
4. Open https://orismaglobal.com after upload.

Important changes you may want:
- Replace trading@orismaglobal.com with your real business email.
- Add company registration number once registered.
- Add privacy policy/terms later if you add forms or tracking.
